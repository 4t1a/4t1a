## What I work on

I care about keeping information intact when logs get compacted, and about counting what a message actually carries. The two main projects below are the same question from two sides: what is in the data, exactly, and can anyone check?

<img src="assets/divider.svg" width="100%" alt="">

## Projects

| Project | What it does | Language |
| :-- | :-- | :-- |
| [**razobill**](https://github.com/4t1a/razobill) | Lossless log compaction engine and exact information ledger, with DuckDB and Python extensions. | C++20 |
| [**Latitude-Doubt**](https://github.com/4t1a/Latitude-Doubt) | Paper, code and reproducibility pipeline for an exact ledger of meaning in messages. | TeX |
